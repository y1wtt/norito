# norito

Rustで構築するデスクトップ向けWYSIWYG Markdownエディタ。

- GUI: Iced（専用のMarkdown編集ウィジェットを実装）
- GUI分割: 汎用Iced拡張 / Markdown編集ウィジェット / アプリ画面。本体パッチは `vendor` で管理
- アーキテクチャ: MVVM + OSサービスのポート／アダプター
- 対象OS: Windows / macOS / Linux
- MVP: 文書編集・保存に加え、フォルダを開いてファイルツリーから文書を切り替える

[設計ドキュメント](docs/design.md)

**基本構文のWYSIWYG直接編集を実装しています。** Markdown原文を正本にし、記法を隠した本文をひとつの編集面で操作します。ソース表示にも切り替えられます。

## 起動

RustのstableツールチェーンとOSのネイティブ開発環境が必要です。WindowsではMSVC C++ビルドツールを使用します。

```sh
cargo run --release -p norito-desktop
```

起動時にフォルダ・文書を指定することもできます。

```sh
cargo run --release -p norito-desktop -- --folder . --file README.md
```

配色と編集を試すサンプルは `examples/notes` にあります。

```sh
cargo run --release -p norito-desktop -- --folder examples/notes --file examples/notes/プロジェクトメモ.md
```

## 試せること

- フォルダを開き、サブフォルダを展開してMarkdownを選択。
- ツリー上部にフォルダ名を表示し、ホバーでフルパスを確認。新規作成先のフォルダはアクセント色で示し、フォルダ名のクリックでルートを作成先に戻します。
- Ctrl+Shift+Nまたは「ファイル → 新規フォルダ」で、選択フォルダ内にディレクトリを作成。編集中の文書は維持します。
- Ctrl+Nまたはツリーのファイル＋アイコンから名前を入力し、Enterで新規ファイルを作成。選択フォルダ内に作成し、.mdは自動補完。Escapeでキャンセル。フォルダ未選択なら無題文書を開き、保存時に場所を指定。
- 単体ファイルを開く、保存、別名保存。
- Markdownファイル（.md / .markdown）をウィンドウにドロップして開く。未保存の変更は保存確認を通します。複数同時ドロップは先頭の1件を扱います。
- 本文の右クリック、またはShift+F10で編集メニューを開く。切り取り・コピー・貼り付け・全選択・Undo/Redo・太字・斜体・コードに対応。Escapeで閉じます。
- 見出し、太字、斜体、インラインリンクのラベル、リスト、引用、コードの直接編集。
- Markdown記法を入力すると整形表示へ変換。リストではEnterで次の項目を作成。
- 選択した文字の太字・斜体・コード書式、現在行の見出し・箇条書き・引用書式。
- Ctrl+/でWYSIWYG／Markdownソースを切り替え。「表示」メニューからサイドバー、明色／暗色も切り替え。
- Undo / Redo、文書切り替え・終了時の未保存確認。
- 保存時の外部変更検出、一時ファイル経由の置換、UTF-8 BOMの保持。
- 加賀棒茶の暗色／明色テーマ。
- 文字選択時に小さな書式バーを表示。太字・斜体・コード・ページリンクを選択位置から操作できます。
- 「挿入 → 表」またはCtrl+Shift+Tで小さな行列グリッドを開き、クリックで挿入。本文のセルを直接編集し、Tab/Shift+Tabで移動、最終セルのTabまたはCtrl+Enterで行を追加します。編集内容は即座に反映され、適用ボタンはありません。行・列の追加削除と整列は選択セル付近のアイコンツールチップまたは右クリックから操作します。
- 「挿入 → コードブロック / Mermaid」で本文にフェンスを挿入し、その場で言語とコードを編集。Escapeで図の表示へ戻します。
- 「挿入 → 画像」で画像を文書と同じ場所の `assets` にコピーし、相対パスで挿入。ページ間リンクも相対パスで挿入します。どちらも先に文書を保存してください。
- 「表示 → 目次・文書ナビゲーション」で見出しジャンプ、リンク移動、画像・Mermaidのプレビュー、表・コードの再編集。本文のリンクは通常クリックで記法を編集、Ctrl+クリックまたはCtrl+Enter（macOSはCommand）でページを開きます。
- Windowsは標準タイトルバーを使わず、norito・メニュー・文書名・ウィンドウ操作を1行に配置。ドラッグ・ダブルクリックでの最大化・四辺と四隅のリサイズに対応。macOSはアプリ内メニューを非表示にし、NSMenuへ統合します。

ショートカットは Ctrl（macOSではCommand）+ N / O / S / Z、Shift + Oでフォルダ、Shift + Sで別名保存、Shift + ZでRedo。

書式は選択した文字に Ctrl+B（太字）、Ctrl+I（斜体）、Ctrl+E（コード）、Ctrl+Shift+Q（引用）。引用は複数行の選択にも対応し、Enterで継続、空の引用行でEnterを押すと終了します。現在行をCtrl+1 / 2 / 3で見出しに変更できます。通常操作は「ファイル・書式・表示」メニューにまとめ、保存や履歴操作の常設ツールバーは置いていません。新規起動時の文書は空です。

本文のキーバインドはCtrl+X/C/V/A、Ctrl+Z、Ctrl+Shift+ZまたはCtrl+Y、Ctrl+0（段落）、Ctrl+1〜6（見出し）に対応。書式・履歴操作は本文にフォーカスがあるときに適用します。ツリーのファイル追加「＋」の隣に、フォルダ作成アイコンを配置しています。

## 編集操作の追加

- ソース表示でも本文・見出し・コードの文字サイズをWYSIWYGと共有します。
- 太字・斜体・コード・取り消し線はカーソルが入ると記号を表示。記号の内外を直接選べます。
- `*` / `_` / バッククォート / `~` / `[` / `(` の閉じ記号を補完。生成した閉じ記号は再入力で通過し、空のペアはBackspaceで削除します。コードフェンスの入力中は補完しません。
- Ctrl+B/I/Eは未選択でも記号を挿入し、内部から入力できます。ソース表示の選択書式にも対応。
- Ctrl+Shift+Xで取り消し線、Ctrl+Shift+Tまたは右クリックで表を挿入。
- フェンスの言語名からコードを色分けし、コード部分を暗い背景で囲みます。
- `~~取り消し線~~`、タスクリスト、水平線、`==ハイライト==`、参照リンク、脚注、YAML front matter、GFM引用を認識します。
- `$...$` / `$$...$$` をネイティブSVGで表示。対応するLaTeX構文はレンダラーの範囲に限ります。`^...^` / `~...~` は現状縮小文字で表示します。
- Ctrl+F/Hで検索・置換。前後の一致へ移動、全置換、大文字小文字、正規表現に対応。全置換は一度のUndoで戻せます。
- 左下の常時「未保存」を廃止し、文書名とツリーに印を表示。処理中とエラーだけ左下に表示します。

[機能対応表](docs/features.md)に、実装済み・制約・未対応を分けて記載しています。

## 構成

| クレート | 責務 |
| --- | --- |
| `norito-model` | Markdown原文、保存済み状態、編集履歴、原文と表示の対応 |
| `norito-viewmodel` | コマンド、文書・ツリーの状態、未保存確認、I/O要求 |
| `norito-platform` | FileStore / DirectoryStore / FileDialog traitと共有型 |
| `norito-platform-native` | ネイティブI/Oとダイアログの具象Adapter |
| `norito-platform-mock` | テスト用メモリ保存Adapter |
| `norito-iced-ext` | 汎用リッチテキスト用HighlighterとGUI補助。Markdownには依存しない |
| `norito-editor-widget` | 単一の編集バッファ、書式・カーソル変換、Modelとの同期 |
| `norito-desktop` | 起動・DI・非同期実行・画面・テーマ |

添付のデザイン資料から色を採用し、`apps/desktop/src/theme.rs` にOKLCHトークンを定義しています。資料内のスクリプトは実行せず、Webサイト固有の表示規則はエディタの機能要件として扱っていません。補助文字は読みやすさのため明度を調整しています。

Icedへの変更は [vendor/README.md](vendor/README.md) に記録しています。文字ごとのサイズ指定、実際の行高に基づくキャレット・選択描画、小さいメニュートリガーと独立したドロップダウン幅を追加しています。

## 現在の制約

- 表・画像・Mermaid・数式は本文内で描画します。表はクリックでセル編集、画像・数式・Mermaidはクリックでその場の原文編集に切り替え、Escapeで表示に戻ります。表の長いセルは折り返さず省略表示します。HTMLは原文を保持し、ブラウザとして実行しません。
- MermaidはRustの互換レンダラーを使用します。公式JavaScript版と全構文・見た目の一致は保証しません。入力は1図32KBまで。
- macOSのNSMenu接続は実装済みですが、このWindows環境ではmacOSのビルド・実機確認は未実施です。
- 画像を伴う文書の別フォルダへの「名前を付けて保存」では、assetsの自動移動は行いません。
- 複雑な書式境界をまたぐ書式コマンドは適用しません。空のコードブロックは入力位置を明確にするためフェンスを表示します。
- IMEの未確定文字は、本文の書式と折り返しを引き継いだ一時レイアウトで表示。確定するまで本文・保存状態・Undo履歴は変更しません。外部変更の常時監視は未実装。
- Windows IMEで本文・文字のある見出しに加え、空のH1への最初の入力も変換中と確定後のサイズ・位置を実機確認。macOS/Linux、DPI変更、スクリーンリーダーの実機検証は未実施。
- 履歴は直近100回の本文スナップショット。Undo時のカーソル復元、連続入力のグループ化、大容量文書への最適化は後続。
- ツリーは展開時に直下を一括列挙。ページングは後続。一覧更新は「ファイル → フォルダを更新」で行い、ルートから展開し直す。
- 保存時の版比較と置換の間には外部アプリとの競合窓が残る。Windows ACL・拡張属性の完全保持、ネットワークボリューム、停電耐性は未検証。
- 本文の改行・空行は原文に対応させて表示します。複雑な入れ子・双方向テキストの編集は追加検証が必要です。
- リンクの外部起動やネットワーク画像取得は実装していません。

## 検証

```sh
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all -- --check
```

描画確認用に `--screenshot target/norito.png` を渡すと、起動後にウィンドウのPNGを保存して終了します。明色は `--light` で指定できます。

スクリーンショット時に `--new-file` を併用すると、名前入力中の状態を確認できます。ファイルは作成しません。

`--new-directory` はフォルダ名入力の描画確認用です。確認画像は `target/norito-light.png` と `target/norito-dark.png` を更新し、古い世代を残さない運用にします。

テストでは、記法を隠した本文への日本語入力、Markdown入力の自動変換、書式をまたぐ削除、リスト継続、全選択置換とUndo、繰り返し文字の挿入位置、原文保持、および可変行高でのクリック・選択・キャレットの一致を確認しています。

IMEの回帰テストでは、空のH1〜H6（単独／前後に本文がある場合）の未確定文字と確定後について、フォント・文字座標・行高・キャレット位置の一致を検証します。空のCommitイベントによるキャンセルで選択中の本文を削除しないことも確認します。
