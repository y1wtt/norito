# 機能対応表

2026-10-12。既存の機能と今回の追加を含む。実装と他OSの実機確認は区別する。

| 機能 | 状態 |
| --- | --- |
| フォルダ・ファイルの新規作成、ツリー、DND | 実装済み。複数ドロップは先頭の文書を開く |
| 保存・別名保存・外部変更の保存時検出 | 実装済み。未保存確認・非同期I/O・Undoを経由 |
| WYSIWYG / ソース切り替え | Ctrl+/。文字サイズを共有 |
| 太字・斜体・コード・取り消し線 | 選択書式、ショートカット、記号の公開、閉じ記号の補完 |
| 見出し・リスト・引用・改行 | 継続・空行で終了・書式分割と結合を回帰テスト |
| IME | 見出しの未確定文字・確定位置を共通レイアウト化。Windowsで確認、他OSは未検証 |
| コードブロック | 言語別の色分けと暗い背景。未登録言語は単色 |
| Mermaid | 通常は図、クリックで本文内コード編集、Escapeで図に戻る |
| 表 | 小さな行列グリッドから挿入、本文のセルを直接編集。Tab移動、Ctrl+Enter行追加、選択セル付近のアイコンツールチップで行列の追加削除・整列、Undo。編集ダイアログなし |
| 画像 | assetsへコピー・相対パス挿入・本文表示・クリックで記法編集 |
| 目次 | 文書ナビゲーションで見出し一覧とジャンプ |
| ページ間リンク・見出し・脚注リンク | Ctrl/Command+クリック、Ctrl/Command+Enter、右クリック、ナビゲーションから移動 |
| 参照リンク・脚注・タスク・水平線 | 認識・表示。タスクはクリックで切り替え |
| 数式 | インライン/ブロックのSVG表示と原文編集。LaTeX全構文互換ではない |
| ハイライト・上下付き文字 | ハイライトは背景色。上下付きは縮小表示のみで、ベースライン移動は未実装 |
| YAML front matter・GFM引用 | 原文保持・ブロック認識。専用プロパティ編集UIはない |
| 検索・置換 | 前後検索、全置換、正規表現、大文字小文字 |
| メニュー・ウィンドウ | Windows独自ヘッダー、中央文書名、macOS NSMenu接続。macOS実機未検証 |
| 未保存表示 | 文書名・ツリーの印。左下は処理中/エラーのみ |

## 残っている差分

機能洗い出しの参考は[Markdown構文リファレンス](https://support.typora.io/Markdown-Reference/)、[記号補完](https://support.typora.io/Auto-Pair/)、[リンク操作](https://support.typora.io/Links/)。完全互換を表す一覧ではない。

- HTML埋め込み・動画・iframe、絵文字ショートコード、本文中の自動TOC記法は未実装。原文を破棄せず表示する。
- PDF/HTML/Office形式へのエクスポート、印刷、カスタムCSS、スペルチェック、数式番号、アウトライン折り畳み、フォーカス/タイプライターモードは未実装。
- 外部URL起動・ネットワーク画像、自動保存、常時ファイル監視、タブ・複数文書の同時編集は未実装。
- MermaidはRustの互換レンダラー。公式JavaScript版との全構文・外観の一致は保証しない。
- 表はセル内の長文折り返し・リッチ書式の描画が限定的。画像は固定の表示枠、インライン数式は幅を推定する。
- macOS/LinuxのIME・メニュー・DPI・アクセシビリティは実機検証が必要。

この差分を完了済みとして扱わない。
