# 編集機能

文字を選択すると、書式バーが表示されます。Ctrl+Bで太字、Ctrl+Iで斜体に切り替えます。

## 表

| 操作 | ショートカット |
| --- | --- |
| 太字 | Ctrl+B |
| 斜体 | Ctrl+I |
| ソース表示 | Ctrl+/ |

## コード

```rust
fn main() {
    println!("norito");
}
```
